# In-House Goal Setting & Tracking Portal

This is a decentralized Goal Setting & Tracking Portal built entirely on the Internet Computer Protocol (ICP).

The platform enables Employees, Managers, and Admins to manage organizational goals, approvals, quarterly check-ins, analytics, and audit trails through role-based dashboards.

---

## Features

### Employee
- Create and manage goals
- Submit quarterly check-ins
- Track goal progress
- View approval status

### Manager
- Review team goals
- Approve or request rework
- Monitor employee progress

### Admin / HR
- Organization-wide dashboard
- Analytics and reporting
- Audit trail monitoring
- Goal cycle management

---

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Vite

### Backend
- Motoko (Internet Computer smart contracts)

### Storage
- On-chain canister state storage

### Hosting
- Internet Computer Protocol (ICP)

---

## Architecture

- Frontend handles UI, dashboards, forms, and analytics.
- Backend manages workflows, approvals, calculations, and audit logs.
- Data is stored directly on-chain using ICP canisters.
- Entire application runs without AWS, Firebase, or traditional servers.
